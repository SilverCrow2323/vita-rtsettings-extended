# Rt:Settings Extended

A native-settings extension project for PlayStation Vita.

The goal is to add coherent, discoverable settings pages to the existing Vita Settings experience rather than create a separate standalone SPDW menu.

## Development status

Project bootstrap. The first implementation milestone is **Tai Saver**: a boot-time backup and recovery system for `ur0:tai`.

See the project documentation and implementation plan on the development branch.
